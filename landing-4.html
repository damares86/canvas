Product Specifications

Complete list of the Tech Specifications for your understanding

Ultra Responsive Template

Canvas is built with a fluid, mobile-first grid that adapts flawlessly to phones, tablets, and desktops without sacrificing visual quality. Resize your browser window at any time and the layout responds instantly. Navigation collapses into a clean hamburger menu on smaller screens while images and typography scale proportionally. You never need to maintain a separate mobile stylesheet — the template handles everything automatically, giving visitors a consistent, professional experience across any device and screen resolution from launch day forward.

Retina Ready Display

Canvas delivers razor-sharp visuals on every high-density display, including the latest Retina and Super Retina screens. All icons ship in scalable vector format, ensuring crisp edges at any zoom level, while images are provided in standard and 2x resolutions so the browser can automatically serve the sharpest asset for each display. Typography is rendered using advanced sub-pixel smoothing so letterforms remain clear even at small sizes. Custom icon fonts load in place of bitmap sprites, slashing HTTP requests while staying perfectly sharp. Product screenshots, team photos, and background images all support 2x srcset attributes out of the box, requiring no additional configuration on your part. The result is a website that looks unmistakably premium on every screen your customers use. Whether browsing on a flagship smartphone or a 5K desktop monitor, every pixel communicates professionalism and attention to detail. Canvas sets the visual bar high and keeps it there across every format your audience might use to discover your brand. High-resolution assets are automatically detected and served with no manual intervention required. Designers and developers both benefit from the organized asset pipeline, which separates standard and retina resources into predictable folder structures that are easy to audit and update as your visual library grows over time.

Unlimited Color Options

Canvas ships with a fully dynamic color system built on CSS custom properties, letting you apply a completely new palette to your entire site in seconds. The advanced admin panel exposes primary, secondary, and accent color variables — simply update a value and every button, heading, link, and highlight across every page updates in unison. Gradient presets, dark-mode overrides, and per-section color schemes are all supported. Design teams can lock brand colors into a theme configuration file so every developer works from the same palette automatically. With over one hundred pre-built color combinations included and the ability to define any custom hex value, Canvas adapts to any brand identity without requiring a single line of custom CSS. Preview your palette live in the browser before committing to a scheme.

Bootstrap v3.2.0 Compatiable

Canvas is built on Bootstrap, giving you access to its full ecosystem of components, utilities, and community plugins straight away. Every grid column, modal, dropdown, tab panel, and tooltip follows the Bootstrap specification exactly, so third-party plugins integrate without conflicts. The codebase is organized into logical partials that map directly to Bootstrap categories, making it easy for any developer familiar with the framework to navigate and extend. Compiled CSS is included alongside SCSS source files so teams can adopt a build process or ship pre-compiled styles immediately with no setup required at all.

Light & Dark Scheme Available

Canvas includes a fully implemented light and dark color scheme that you can activate on any page, section, or individual element simply by adding a single class. The dark class applied to the body element switches the entire site to a sleek, low-light palette suited for creative agencies, tech products, and modern portfolios. Every component — navigation, cards, modals, buttons, forms, and footers — ships with both light and dark variants that are automatically activated based on the parent class. For granular control, the scheme can also be toggled per-section, allowing you to mix contrasting areas on the same page for visual hierarchy. Users who prefer a system-level preference can benefit from the built-in prefers-color-scheme media query support, ensuring the initial page load matches their OS preference. Switching schemes requires zero design rework and no duplicate templates — Canvas manages the full transition through a clean CSS architecture that is straightforward to extend and maintain.
