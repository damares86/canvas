# Install: pip install canvasorbit
import canvasorbit as co
# Initialize with your API key

Yes. You set per-card budgets, per-transaction caps, merchant category locks, single-use mode, expiry windows, and approval thresholds. When a card hits a limit it declines instantly, no manual review required.
Funds sit in a segregated custodial account at our partner bank, FDIC-insured up to $250,000 per account. CanvasOrbit never has access to your wallet funds for our own use. Only authorized API keys tied to your account can issue cards or move money.
When an agent triggers a transaction that exceeds your approval threshold, CanvasOrbit pings the human approver via Slack, email, SMS, or a custom webhook. The approver taps approve or deny and the agent gets the answer in under 200ms on average.
