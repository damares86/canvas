Product Specifications

Complete list of the Tech Specifications for your understanding

Ultra Responsive Template

Canvas is built on a fully fluid grid system that adapts seamlessly to every screen size, from mobile handsets to large desktop monitors. Each component is designed with responsive principles baked in—layouts shift intelligently, images scale proportionally, and navigation collapses cleanly into a touch-friendly mobile menu. Resize your browser window at any point to see the responsive behavior in action across every page section of the template.

Retina Ready Display

Every graphic, icon, and UI element in Canvas has been crafted and exported at double resolution, ensuring your site looks razor-sharp on HiDPI and Retina displays. From the navigation logo to the footer illustrations, nothing appears blurry or pixelated regardless of the device pixel ratio. Icon fonts such as Bootstrap Icons and Font Awesome render crisply at every scale, while all bundled photography is sourced at high resolution to maintain visual fidelity throughout. Canvas also supports srcset attributes on key images, allowing browsers to request the most appropriate resolution automatically without any manual intervention from the developer. Premium sliders, modal windows, and lightboxes all uphold this visual quality standard, meaning the end-user experience is consistently polished on both standard and high-density displays. Navigation icons, feature illustrations, and decorative graphics each appear crisp and detailed even on the sharpest screens available today. This meticulous attention to visual quality sets Canvas apart and ensures your brand always looks professional, no matter what device a visitor uses to access your website. Teams that care about pixel-perfect presentation will immediately appreciate the care invested in every visual asset bundled with this template.

Unlimited Color Options

Canvas ships with an extensive palette of pre-defined color schemes and supports unlimited custom color combinations. Using the built-in theme color variable, you can change the primary accent color site-wide with a single CSS update—no need to hunt through dozens of files. Gradient overlays, solid fills, and transparent backgrounds are all easily toggled per section. Light and dark variants are included for every component, giving you fine-grained control over contrast and mood. Additional theme packs expand the starting palette further, while the well-documented SCSS source files let designers build entirely custom palettes from the ground up. Color-coded utility classes follow Bootstrap conventions, so applying a brand color to a button, card, or heading requires nothing more than a single class name.

Bootstrap v3.2.0 Compatiable

Canvas is fully compatible with Bootstrap 3.2.0 and takes full advantage of the framework's responsive grid, utility classes, and JavaScript plugins. All third-party components have been tested to work alongside Bootstrap without conflicts or overrides that could break default behavior. The template structure follows Bootstrap's semantic HTML conventions, making it straightforward for developers already familiar with the framework to extend or modify any section. Future Bootstrap updates are handled gracefully thanks to a modular CSS architecture that separates core framework styles from Canvas-specific customizations.

Light & Dark Scheme Available

Canvas supports both a light and a dark color scheme, and switching between them is as simple as adding the dark class to the body element. Every component—headers, footers, cards, navigation menus, form fields, and modals—has been designed and tested in both modes to ensure visual consistency and accessibility standards are met. Section-level dark or light overrides are also available, letting you mix schemes within a single page for dramatic visual contrast. The dark scheme uses carefully chosen background shades and text colors that maintain a comfortable reading experience without sacrificing the overall aesthetic. Typography contrast ratios meet WCAG AA guidelines in both modes, and interactive elements like buttons and links adjust their hover states accordingly. This dual-scheme architecture makes Canvas suitable for a wide range of industries, from creative agencies that favor bold dark presentations to corporate clients who prefer clean, bright layouts. No additional configuration or tooling is required to enable the dark mode—it works out of the box from the moment you apply the class.
